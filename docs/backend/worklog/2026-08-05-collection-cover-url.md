# Collection에 표지 이미지 URL을 저장한다

- **날짜**: 2026-08-05
- **추적**: Jira 작업
- **관련**: docs#49 (08 §7.4·7.7, 06 §2.6) · front#99

프론트가 이미지 서비스로 생성·선택한 표지 일러스트를 컬렉션과 함께 보여주기 위해
`core.collection`에 `cover_image_url varchar(300) NULL`을 더하고(V8), PATCH를 제목·표지
수정으로 확장했다. 파일은 이미지 서비스가 PVC에 영속 보관·서빙하는 것을 확인했으므로
core는 최종본의 같은 origin 상대 경로만 저장한다 — back이 파일을 직접 받는 안은
k8s 컨테이너의 런타임 파일 쓰기가 재배포에서 살아남지 못해 기각했다.

판단 두 가지: ① 표지 제거는 MVP에서 뺐다. Jackson이 String에서 "필드 부재"와 "null
명시"를 구분하지 못해 null을 제거로 해석하면 제목만 고칠 때 표지가 지워진다. null·생략
모두 유지이고 교체만 지원한다. ② URL은 `^/image/files/[A-Za-z0-9._-]+\.webp$` 패턴을
요청 DTO에서 검증한다 — 프론트가 보낸 값을 그대로 믿으면 임의 문자열이 표지로 저장된다.

`coverImageUrl`은 컬렉션이 실리는 모든 응답(7.1 생성·7.2 목록·7.3 상세·8.1 책장 탐색·
9.2/9.3 팔로우 책장·10.1 피드)에 null 그대로 실린다 — 프론트가 키 부재와 null을 구분할
필요가 없어야 한다.
